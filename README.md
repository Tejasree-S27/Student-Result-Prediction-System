# 🎓 Student Result Prediction System

A Machine Learning web application built using **Python**, **Streamlit**, and **Scikit-Learn** to predict whether a student will **Pass** or **Fail** based on academic performance.

## 📌 Features

- Predict Student Result (Pass/Fail)
- Data Analysis Dashboard
- Model Performance Metrics
- Feature Importance Visualization
- Interactive Streamlit UI

## 🛠 Technologies Used

- Python
- Streamlit
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-Learn

## 📊 Input Features

- Study Hours
- Attendance
- Previous Marks
- Assignments Done
- Sleep Hours

## 🤖 Machine Learning Model

- Logistic Regression

## 📈 Performance Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## 🚀 Installation

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
